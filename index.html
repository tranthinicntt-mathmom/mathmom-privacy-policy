Introduction

Math & Mom is an educational application designed for children aged 2 to 7 years old. This Privacy Policy explains how information is collected, used, and protected when using the application.

Information We Collect

The application does not require users to create an account and does not intentionally collect personally identifiable information such as name, email address, phone number, or home address.

To improve the quality and stability of the application, we may use third-party services such as Firebase Analytics and Firebase Crashlytics, which may collect anonymous usage information, including:

  • Device type
  • Operating system version
  • Application performance data
  • Crash reports
  • Anonymous usage statistics

How We Use Information

  • Improve application performance
  • Fix bugs and crashes
  • Enhance user experience
  • Understand feature usage trends

Children's Privacy

Math & Mom is intended for children. We do not knowingly collect personal information from children. If you believe that personal information has been collected unintentionally, please contact us so that we can promptly delete the information.

Data Sharing

We do not sell, rent, or share personal information with third parties.

Data Security

We take reasonable measures to protect information and ensure the security of the application.
